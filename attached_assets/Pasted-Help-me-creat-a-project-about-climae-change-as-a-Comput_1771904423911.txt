1. Java Backend (The Central Server)
This Spring Boot code creates an endpoint to receive salinity data from your IoT sensors and triggers an alert if the water becomes too salty (saltwater intrusion).

SalinityController.java

Java
import org.springframework.web.bind.annotation.*;
import java.util.Date;

@RestController
@RequestMapping("/api/v1/wara-monitor")
public class SalinityController {

    // Threshold for saltwater intrusion (example: 500ppm for fresh water)
    private static final double SALINITY_THRESHOLD = 500.0;

    @PostMapping("/data")
    public String receiveData(@RequestBody SensorData data) {
        System.out.println("Received reading from: " + data.getSensorLocation());
        System.out.println("Salinity Level: " + data.getValue() + " ppm");

        if (data.getValue() > SALINITY_THRESHOLD) {
            triggerSmsAlert(data);
            return "ALERT: High Salinity Detected!";
        }

        return "Data Logged Successfully";
    }

    private void triggerSmsAlert(SensorData data) {
        // Here you would integrate with an SMS API like Twilio
        System.out.println("!!! SENDING SMS TO COMMUNITY LEADER !!!");
        System.out.println("Alert: Well at " + data.getSensorLocation() + " is unsafe.");
    }
}

class SensorData {
    private String sensorLocation;
    private double value;

    // Getters and Setters
    public String getSensorLocation() { return sensorLocation; }
    public void setSensorLocation(String sensorLocation) { this.sensorLocation = sensorLocation; }
    public double getValue() { return value; }
    public void setValue(double value) { this.value = value; }
}
2. ESP32 Firmware (The Sensor Code)
Since Java doesn't run natively on an ESP32, use this C++ code to read the sensor and "talk" to your Java server.

WaraMonitor_Sensor.ino

C++
#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_PASSWORD";
const char* serverUrl = "http://YOUR_JAVA_SERVER_IP:8080/api/v1/wara-monitor/data";

const int sensorPin = 34; // Pin connected to the Salinity Sensor

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(1000); }
}

void loop() {
  int sensorValue = analogRead(sensorPin);
  // Simple conversion formula based on sensor calibration
  float salinityPpm = sensorValue * (3300.0 / 4095.0); 

  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(serverUrl);
    http.addHeader("Content-Type", "application/json");

    String jsonPayload = "{\"sensorLocation\":\"Hanuabada Village\",\"value\":" + String(salinityPpm) + "}";
    
    int httpResponseCode = http.POST(jsonPayload);
    http.end();
  }
  delay(60000); // Read every 60 seconds
}

3. The SMS Service Logic
This service initializes the Twilio connection and contains a method to send the alert.

SmsService.java

Java
import com.twilio.Twilio;
import com.twilio.rest.api.v2010.account.Message;
import com.twilio.type.PhoneNumber;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import javax.annotation.PostConstruct;

@Service
public class SmsService {

    @Value("${twilio.account.sid}")
    private String accountSid;

    @Value("${twilio.auth.token}")
    private String authToken;

    @Value("${twilio.phone.number}")
    private String twilioNumber;

    @PostConstruct
    public void initTwilio() {
        Twilio.init(accountSid, authToken);
    }

    public void sendClimateAlert(String to, String villageName, double salinity) {
        String alertMessage = "WARA ALERT: High salinity (" + salinity + " ppm) detected at " 
                              + villageName + ". Water is unsafe for drinking.";
        
        Message.creator(
            new PhoneNumber(to),        // To: Community Member
            new PhoneNumber(twilioNumber), // From: Your Wara-Monitor Number
            alertMessage
        ).create();
    }
}
